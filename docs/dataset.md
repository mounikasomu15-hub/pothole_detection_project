# Dataset
Required: ~5000 road images with binary pothole masks, matched by file stem.
```
dataset/images/image_0001.jpg    dataset/masks/image_0001.png   (0 = background, 255 = pothole)
```
No real data is bundled and none is fabricated. Tools: `preprocessing/prepare_dataset.py` (import/convert), `scripts/validate_dataset.py` (checks),
`preprocessing/split_dataset.py` (70/15/15 copy into train/val/test, manifest in `outputs/reports/dataset_split.csv`).
Report your dataset's real source, licence and size in the thesis. `dataset/severity_labels.csv` is generated by `scripts/generate_feature_dataset.py`
and labelled by `scripts/assign_severity_labels.py` or by hand; the `severity_source` column records the origin of each label.
